DSA Concepts Used

Graph

Locations are represented as vertices and roads as weighted edges.

Adjacency List

The road network is stored using adjacency lists.

Min Heap

A manually implemented min heap is used to select the nearest location.

Dijkstra

Dijkstra's algorithm finds the shortest route between locations.
